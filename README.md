# metabase-preview-demo

Demo content repo for the Metabase PR-preview prototype
(see the pr-preview-github-app plan). Serdes content-only export built against the
**Sample Database** — no data model, no settings, no secrets. All references are
name paths; the serving instance provides its own Sample Database.

Open a PR against this repo and add the `mb-preview` label (or mention `@metabase`
in a comment) to get a live preview instance.
